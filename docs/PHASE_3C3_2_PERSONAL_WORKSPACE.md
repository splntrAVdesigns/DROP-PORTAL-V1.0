# Phase 3C.3.2 — Personal workspace and Tuner parity

- The signed-in home view restores the ASCII portal hero and an Edit Layout control beside My Tuner. Upcoming and Results can swap order or toggle width. Layout is saved under the signed-in account ID on that device, so two accounts sharing a browser do not inherit each other's arrangement. It does not yet sync across devices.
- Routine drop polling, feedback saves, and layout edits preserve the current result/player DOM when the result data is unchanged. A new result intentionally replaces the prior result.
- The Tuner order is Base / This Week, weekly plan, One Time Dig, discovery focus, artists and labels, Fine Tune, then history and privacy. Names are plain text remove buttons. Focus controls are segmented and cyan when selected. The private dialog uses dark gray surfaces.
- All nine public Fine Tune sliders are visible and stored in the private profile. Future, Deep and Jungle lane weights, track count, verified release window, preferred artists and labels, and Label Specific continue to affect personal selection. Discovery Depth now balances the older and newer parts of the verified release window. Experimental Bias now adjusts the catalog's verified Future / Experimental lane.
- Floor → Headphones, Darkness, and Break Density remain stored, but the published catalog has no verified audio measurements for them. The UI names this coverage gap. Include DJ Mixes remains unavailable until verified mix sources exist. The Archives, Future, Anthem, and Groove remain unavailable until their research/audio evidence can drive a genuine result.
- No new SQL migration or environment variable is needed for this UI sprint. The worker and production schedule still need a successful live run to confirm publication.
